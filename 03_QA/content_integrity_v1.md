# CONTENT INTEGRITY / QUALITY GATE v1.0

## 1. ORIGINALITY

Original Mode:

- no hidden competitor replication;
- creator-defined positioning is preserved;
- episode concepts are original in execution.

Reference Mode:

- structural learning is allowed;
- exact creative execution is not copied.

Reject or rewrite:

- copied distinctive sentences
- copied scenes
- copied characters
- copied thumbnails
- cloned brand language

## 2. ANTI-GENERICITY

Every section must perform a function:

- explain
- demonstrate
- investigate
- compare
- reveal
- contextualize
- resolve
- advance the story

Remove filler, repetition, unsupported superlatives, and generic B-roll instructions.

## 3. FACTUALITY

Where factual claims matter, classify them as:

- verified fact
- estimate
- forecast
- attributed claim
- interpretation
- uncertainty

Never silently upgrade a lower-confidence category.

## 4. NUMERIC CLAIMS

For important numbers preserve:

- value
- unit
- date
- geography/population
- denominator where relevant
- source context

Do not fabricate precision.

## 5. VISUAL TRUTH

A generated visual may be illustrative, but it must not silently communicate a false factual mechanism.

For engineering/science/infrastructure/documentary channels:

- distinguish explanatory simplification from real-world structure;
- use diagrams/cutaways where appropriate;
- label forecasts/estimates when the visual could otherwise imply certainty.

## 6. ENTITY / CHARACTER CONSISTENCY

Check:

- canonical colors
- shape/silhouette
- clothing/markings
- recurring props
- environmental continuity
- scale relationships
- camera perspective

## 7. SCENE QA

Every scene must have:

- clear purpose
- coherent start/end state
- complete action timeline
- matching camera description
- audio/narration guidance
- render lock

## 8. EXPORT QA

Before handoff:

- Screenplay Metadata is separate from VEO3 Prompt.
- VEO3 Prompt is plain text.
- No unresolved placeholders remain.
- No accidental project-control text is embedded in the video prompt.
- Thumbnail prompts specify `1707x282` exactly.
- Thumbnail output uses width `1707` pixels and height `282` pixels without cropping, padding, or aspect-ratio changes.
